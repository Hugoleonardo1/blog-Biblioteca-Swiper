# Galeria de Blog — SENAI

Projeto feito com Next.js, React e Swiper, inspirado na referência visual enviada.

## Como executar

1. Instale o Node.js (versão 20 ou superior).
2. No terminal, entre na pasta do projeto e execute:

   ```bash
   npm install
   npm run dev
   ```

3. Acesse `http://localhost:3000` no navegador.

Para gerar a versão de produção, execute `npm run build` e depois `npm run start`.

As imagens dos três primeiros cards estão salvas em `public/images`.
